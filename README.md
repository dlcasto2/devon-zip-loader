# Devon ZIP Loader

A standalone Next.js 16 + Turbopack tool for preparing the `dlcasto2/db-v2` source archive for a custom, server-backed Devon preview deployment.

This project is independent of `devon://apps`. It validates the Devon source ZIP and exports a Docker-ready deployment package. It does not modify Devon's existing browser-extension importer.

See the application UI and generated `DEVON-PREVIEW-DEPLOYMENT.md` for usage and hosting details.
